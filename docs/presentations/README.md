# FactorZen 答辩讲解材料

**受众**：懂代码、不要求熟悉量化。  
**时长**：≤10 分钟（含演示）。  
**讲解重点**：**多 Agent 因子挖掘**（`fz mine team`：4 角色 + Evaluator）。

## 交付物

| 文件 | 说明 |
|------|------|
| **FactorZen_答辩讲解.pptx** | **20 页**宽屏 PPT |
| **讲解稿与演示脚本.md** | 术语白话、主线口播、演示与问答 |
| `factorzen_defense.js` | 生成脚本 |

## 重生成

```bash
cd docs/presentations
npm install   # 首次
node factorzen_defense.js
```

## 结构一览

| 页 | 内容 |
|----|------|
| 1–4 | 封面、大纲、软件定位、**术语超白话** |
| 5–6 | 项目意义（痛点、目标函数） |
| **7–12** | **多 Agent 主线**（为何拆角色、编制、流水线、记忆、防翻车、CLI 演示） |
| 13–14 | Lift 门禁、产物/Web 演示 |
| 15–18 | 技术栈、源码地图、伪代码、铁律 |
| 19–20 | 总结、Q&A |

超时保 **7–12**；可跳 14、15、18。
